# Android 布局与词本操作

整理日期：2026-10-18。依据 2026-10-11 的 2.0.20 实施记录；本次未重建或操作手机。历史设计、测量与各版交付见[布局审查记录](../review/english_word_master_apk_layout.md)。

## 安全区和紧凑布局

- APK 使用 Android 原生 WindowInsets 避让状态栏、导航栏、刘海与键盘，关闭 Capacitor 的重复 CSS 安全区注入；网页仍使用浏览器安全区。
- 保留系统字体缩放，安全区背景跟随主题。卡片高度随内容与字体缩放变化，不保证固定可见张数。
- 手机词库和词本入口采用单栏：图标、名称和右侧数量同行居中，长名称省略；目录路径支持换行，桌面保留原卡片大小与说明。
- 单词卡允许词头与音标同行，释义默认两行摘要并可展开，例句通过入口展开中英文。移除重复色块、边框和内边距，保留完整内容。
- 测试卡仅保留卡内题号；答对提示为“回答正确”，原连续答对三次自动掌握逻辑保留。词数使用目录元数据，不把文件字节数当词数。

## 词本菜单与数据范围

- 生词本与熟词本入口长按 480ms 打开菜单；移动超过 10px 取消，长按松手不进入详情，同时支持右键与键盘。
- 详情保留返回、搜索、排序及“测试词本”；移除原批量管理工具栏与全局清空回调。
- 实际词本菜单提供导入、导出、测试、删除；全量、近期、高频等系统筛选分组只提供导入、导出、测试，不提供清空。
- 导入、导出以选中词本或分组为范围。删除词本及成员关系，仅清除无其他词本引用的词条学习记录；共享词及其他词本的学习记录保留。
- 内置词本的删除状态持久化，APK 标准资源继续用于默认四级测试。
- APK 导出接入系统文件保存选择器，网页沿用文件下载。
