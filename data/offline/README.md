# 内置离线词集

八个词本：初一、初二、初三、高一、高二、高三、大学四级、大学六级。默认测试大学四级。

## 来源与口径

- 初中使用现有 `english-word-enriched` 包中人教版七年级上、下册，八年级上、下册和九年级全册词表。该整理数据没有明确的新教材修订年份，不能称为已经逐词核验的 2024 新版教材词表。
- 高一合并人教版高中必修第一至三册；高二合并选择性必修第一至三册；高三使用选择性必修第四册。这是用户确认采用的常见教学进度划分，不代表全国统一的分年级要求。
- 四、六级范围来自教育考试院公开的[《全国大学英语四、六级考试大纲（2016年修订版）》](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)。`cet-source-rows.json` 为该 PDF 词表的文字转录：星号行列为六级新增范围，六级词本包含四级基础范围。
- 大纲同一词目下的派生词、可选拼写和美英拼写变体展开成学习条目，并按词 ID 去重；所以学习条目数量不同于大纲印刷词目数。转换脚本统一处理 PDF 的连字符、缩写拼写和少量转录异常。
- 大纲本身不提供释义、音标或例句；这些内容使用现有预整理词典。词典未收录的基本词 `a` 和 `I` 在脚本中补充了本地释义、音标与例句。

## 重建

在项目根目录运行 `node scripts/build-offline-vocabulary.mjs`，需要现有的 `data/english-word-enriched` 输入包。

输出为 `public/offline/vocabulary.bin`（gzip 压缩内容）：八本词集共享一个去重词典。使用 `.bin` 避免 Android AAPT 自动解压、改名 `.gz` 资源而造成读取路径不一致。2026-10-11 生成版本共 9,621 个唯一条目，未压缩 2,545,554 字节，压缩 934,785 字节。词本数量分别为 948、995、671、1,258、1,111、346、6,293、8,010。

APK 打包该文件，读取、搜索、测试、保存本地学习记录均无需登录或访问远程词库 API。只将个人新增词条及学习记录写入 localStorage；内置完整词集不重复存入 localStorage。原有联网词库和云端同步保持独立。
